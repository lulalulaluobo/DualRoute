# OpenWrt 插件需求与飞牛应用核对

核对日期：2026-10-30。第一版已部署到 QWRT，用户已确认手机国内/国外访问和蜂窝网络访问家庭飞牛正常。安装与回退命令见 [使用说明](openwrt-usage.md)。

## 已确认需求

采用系统原生 Tailscale 与 Linux 策略路由；管理界面运行在 QWRT/OpenWrt。

- 登录与连接状态、设备列表、选择已获授权的在线 VPS 出口。
- 子网路由广播：允许 Tailnet 设备通过软路由访问家庭局域网；路由还需在 Tailscale 控制台获批。
- 接受子网路由：允许本地设备访问其他节点广播且已获批的远端网段。
- 本机广播为出口与使用其他 VPS 出口是不同功能，界面须明确区分，冲突组合按运行版本能力校验。
- IPv4 国内地址直连家庭宽带，其余公网地址走所选 VPS。局域网、Tailnet 和已接受的远端子网优先于公网分流。
- Tailscale 的组网配置独立于公网接管模式；切换 OpenClash/分流时不得清除子网广播、已接受路由等偏好。
- OpenClash 与 Tailscale 公网分流互斥；切换失败可回退，重启后恢复保存配置。
- 服务日志、DNS 查询日志和连接记录；连接记录显示来源、目标 IP/端口、协议、流量和实际路径。不得将此称为完整 HTTPS 请求日志。
- IPv6 的接管范围与绕行风险须在启用前明确处理，不得将 IPv4 分流标为双栈分流。

第一轮使用 BWG 出口。子网配置的实现与默认启用是两个步骤：先读取并保留当前偏好，避免启用冲突网段。

## 飞牛应用识别

用户截图：发布者「徐大大」，已安装版本 1.102.3，商店展示版本 1.104.1。具有仪表盘、连接配置、高级功能、设备列表、拓扑网络、日志和 Taildrop 监控。

目前未找到能明确对应该发布者与截图的源码仓库及许可证，因此不能断言该管理界面已经开源，也不能将其他同名项目认定为该应用。

已检查的相似项目：

- https://github.com/mynono33/tailscale-fnos ：manifest 的 distributor 为 huangzhe，版本 1.94.2；界面入口 index.cgi 为 ELF 可执行文件，未发现明确的仓库开源许可证。不能作为已确认可复用的界面源码。
- https://github.com/Steven-ZYC/Tailscale-for-fnOS ：包含自行实现的 Go 后端与界面源码，README 明确表示原创打包代码尚未选择许可证。界面组织及发布信息也不能确认与用户截图相同。

Tailscale 核心代码与飞牛第三方管理界面必须分别核实来源和许可证。后续若取得截图应用的源码链接，再评估复用；现阶段可参考其功能组织，继续复用软路由现有 Tailscale 服务。

## 官方行为依据

- 出口节点：https://tailscale.com/docs/features/exit-nodes
- 子网路由：https://tailscale.com/docs/features/subnet-routers

路由优先级设计：本地局域网 → Tailnet/获准远端子网 → 国内 IPv4 直连 → 其他公网 IPv4 走 VPS。远端网段与本地网段重叠时应报冲突，不能直接强制覆盖。
