IPv4 分流顺序

  1. 家庭局域网：保持本地访问
  2. Tailnet 与接受的远端子网：走对应设备
  3. 国内 IP 与额外直连规则：走家庭宽带
  4. 其余公网 IPv4：走所选 VPS

第一版只管理 IPv4。客户端若从主路由获得 IPv6 默认路由，IPv6 可能绕过本机；本页面不表示已实现 IPv6 分流。
